초근 누구 사용안내

도움말

1. NEIS 자료 업로드→2. 카드자료 선택 업로드→달력에서 확인

NEIS 초과근무 최종자료를 날짜별로 정리하고, 필요하면 BC카드 사용내역과 함께 특근매식비 검토를 도와주는 확인 보조 도구입니다. 처음이라면 상단의 초근누구 체험하기로 가상자료를 바로 둘러볼 수 있습니다.

사용방법
  1. NEIS 초과근무 자료를 업로드합니다. 파일을 업로드 영역에 끌어다 놓거나 파일 선택 버튼을 사용할 수 있습니다. 나이스의 급여 → 복무 → 초과근무관리 → 초과근무확인에서 내려받은 엑셀 또는 CSV를 사용할 수 있습니다.
  2. 월간 달력에서 날짜별 초근자 수와 실제 초과근무시간을 확인합니다.
  3. 날짜를 누르면 오른쪽 상세영역에서 해당일 초근자와 실제 근무시간을 확인할 수 있습니다.
  4. 필요한 경우 BC카드 승인내역 또는 이용내역 엑셀/ZIP을 같은 방식으로 추가해 식비 후보금액을 함께 비교합니다.

카드 자료 없이 초과근무 자료만 업로드해도 사용할 수 있습니다.

식비 판정

식비후보는 카드 사용내역 중 특근매식비로 확인해볼 필요가 있는 사용건을 후보로 보여주는 기능입니다.

매식 가능액 = 실제 초근 인원 × 1인 기준금액으로 계산합니다. 기본 기준금액은 9,000원이며 화면에서 변경할 수 있습니다.

충족

식비 후보금액이 초근 인원 기준 가능액 이내

초과

식비 후보금액이 기준 가능액을 초과

근거없음

식비 후보는 있으나 해당 날짜에 실제 초근자가 없음

중요: ‘충족’은 지급 가능 여부를 최종 확정한다는 뜻이 아닙니다. 실제 대상자, 사용 목적, 원인행위 및 증빙자료를 별도로 확인해 주세요.

화면 보는 법

월간 달력은 날짜별 현황을 빠르게 찾기 위한 화면입니다. 초근자가 많은 날에는 일부 이름만 표시하고 나머지는 +N명으로 정리합니다. 전체 내역은 날짜를 클릭해 오른쪽 상세영역에서 확인하세요.

개인정보

업로드한 파일은 서버로 전송되지 않고 현재 브라우저 안에서만 분석됩니다.

페이지를 새로 열어 사용할 때 다시 필요한 파일을 업로드하는 방식입니다. 실제 업무자료를 다루는 만큼 공용 PC에서는 사용 후 화면과 다운로드 파일을 확인하고 브라우저를 닫아주세요.

초근 누구는 자료를 보기 쉽게 정리하는 확인 보조 도구입니다. 최종 인정 여부는 기관 기준과 증빙자료를 함께 확인해 주세요.
